# Portraits — fichiers d'origine

Les deux portraits tels qu'ils ont été fournis, 1080 × 1350, avec la légende
incrustée en bas (`CREATIVE DIRECTION / TANGUY ACCARD`,
`CHEF / EUGENIE COLLEVILLE`).

Ce dossier n'est **pas** servi par le site : c'est la copie de référence. Les
fichiers utilisés dans les fiches Creators sont
`public/images/signature/*-portrait.webp`, dérivés de ceux-ci — la légende
recadrée, et de l'air ajouté au-dessus de la tête.

Pour refabriquer les fiches à partir d'un cadrage plus large, il faudra un
fichier d'origine antérieur à ce recadrage serré : celui-ci s'arrête déjà au
menton, sans les épaules.
